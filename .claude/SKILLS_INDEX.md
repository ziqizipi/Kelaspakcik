# Claude Skills Index

Quick reference for available skills in this project.

## Usage
```
Use Skill tool: skill: "skill-name"
```

## Available Skills

| Skill | When to Use |
|-------|-------------|
| `component-dev` | Building UI components |
| `api-debug` | Debugging API routes |
| `verification` | Before completing any task |
| `nextjs-16` | Next.js 16 App Router work |

## Memory Files

| File | Purpose |
|------|---------|
| `memory/preferences.md` | User's working style |
| `memory/lessons/_index.md` | Mistakes to avoid |
| `memory/patterns/_index.md` | What works well |
| `memory/context.md` | Current project state |

## Before Any Task

1. Check `memory/preferences.md` — know user's style
2. Check relevant skill — follow the procedure
3. Do the work
4. Use `verification` skill — verify before completing
5. Update `memory/lessons/_index.md` if learned something new
