# BalasBro AI Automation Platform

BalasBro.ai is an intelligent automation platform designed to bridge high-touch human communication with high-tech AI automation. 

## Structure
- `index.html`: Entry point of the web app.
- `css/`: Stylesheets based on the design system.
- `js/`: Application logic and routing.
- `DESIGN.md`: Design system documentation.

## Running Locally
Since this is a standard HTML/JS/CSS application, you can run it using any local static server:
```sh
npx serve .
```
Or you can use a VS Code extension like Live Server.
