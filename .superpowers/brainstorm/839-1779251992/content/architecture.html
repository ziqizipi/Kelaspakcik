App Shell Architecture

How should the authenticated app pages be structured?

A

Dashboard + Sidebar Layout

Fixed left sidebar with: Dashboard, Conversations, Orders, Settings. Top bar shows tenant name + user avatar + logout.

B

Dashboard + Collapsible Sidebar

Same as A but sidebar collapses to icons on smaller screens. Mobile gets a bottom tab bar instead.

C

Dashboard + Top Nav

Horizontal top navigation with dropdown menus. No sidebar — more content area, but harder to scale with many sections.
